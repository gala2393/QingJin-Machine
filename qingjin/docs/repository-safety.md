# 公开仓库与私有配置

## 公开入口

网站首页：[www.qingjinmachinery.cn](https://www.qingjinmachinery.cn)。

公开源码提供可复现的程序、数据库迁移和配置模板，不提供生产凭据或部署专属备案信息。

## 必须留在仓库外的内容

| 内容 | 仓库中的处理方式 |
| --- | --- |
| 数据库连接及密码、JWT 密钥、令牌 | `.env.example` 留空，在被忽略的 `.env` 中填写 |
| 真实管理员账号及密码 | 不记录；仅通过私有环境配置或安全输入初始化 |
| 页脚部署专属信息 | `ICP_RECORD_NUMBER=` 留空，构建时由部署环境注入 |
| SSH / TLS 私钥、P12 / PFX / JKS 等密钥容器 | 由运维方单独保管，受 `.gitignore` 规则排除 |
| 数据库数据目录、备份、上传文件及构建产物 | 不提交；按部署指南单独备份及迁移 |
| 公安联网备案数据码 | 不公开，也不作为网页展示内容 |

证书文件名和空配置项不是证书或密钥内容。数据库迁移中的结构 SQL 属于源码，不是生产数据导出。

## 初始化示例

`admin` / `1234567890` 仅是隔离的本地空数据库初始化示例，不是生产凭据，不会在服务启动时自动创建。完整命令见 [系统说明](../README.md#api)。

`db:dev` 和演练脚本中的固定数据库口令仅供本地开发及测试，不能配置为生产口令。生产应使用独立随机密码及随机 JWT 密钥。

## 提交与更新

- 提交前检查暂存文件名及差异。`.gitignore` 不会自动删除已经被 Git 跟踪的文件。
- 不使用强制添加命令绕过私钥、环境文件和运行数据的忽略规则。
- 真实值填写后不得复制回模板、示例命令、截图或日志。
- 已上线站点更新可配置页脚前，先保留并核对服务器私有配置，不能用仓库空值替代。
- 仓库推送不部署线上服务，也不修改现有管理员账号或页脚。

## 历史清理边界

仓库所有者已授权对 Git 历史中的真实备案号脱敏，保留其他功能记录、原作者及日期。受影响的提交及标签哈希会变化，已有克隆应重新同步，不能把旧历史重新推回远程。

分支和标签更新不能保证第三方克隆、分叉及平台缓存中的旧副本消失。若真实私钥或凭据曾经公开，必须撤销或轮换，不能只依赖删除文件或改写历史。
