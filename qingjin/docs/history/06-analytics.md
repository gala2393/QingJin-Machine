# 访问统计与指标口径

## 事件来源

展示站采集 pageview、search、compare 和 inquiry，帮助了解设备关注度、搜索需求、访问来源及联系入口点击。

事件清洗限制路径、语言、机型标识、搜索词长度及结果数量；路径去掉查询参数与片段，无效事件可静默丢弃。机器人规则覆盖常见爬虫、监控与自动化浏览器，但不等于完整反作弊系统。

## 匿名标识和数据保留

访客标识使用日期、IP 和 User-Agent 的 HMAC，每日变化；原始事件模型不保存原始 IP 字段。登录与操作审计是另一套记录，可以包含 IP，不能把统计口径推广为整个系统无 IP 记录。

默认业务时区 Asia/Shanghai；周期汇总间隔 10 分钟，当日查询有 1 分钟新鲜度控制。原始事件默认保留 180 天，配置下限为 30 天，每日统计单独保存。

## 指标解释

| 指标 | 口径及限制 |
| --- | --- |
| PV | 有效页面浏览次数 |
| UV | 每日去重访客，多日值是每日值之和，不是跨日独立人数 |
| 热门机型、页面与来源 | 有效事件排行，受采集与过滤完整性影响 |
| 搜索、无结果搜索 | 用于改进命名、产品目录和搜索体验 |
| 询盘渠道 | 联系入口点击，不等于送达、有效询盘或成交 |
| 最近 30 分钟 | 基于原始事件计算近期访问 |

概览支持与上一同长度范围比较，最大范围 366 天。历史渠道枚举保留 form，当前联系页没有表单，需区分数据兼容性和实际入口。
