# 站点设置与联系渠道

## 配置范围

站点设置统一管理中英公司名称、口号、工厂及资质介绍语、地址、电话、邮箱、WhatsApp、微信、关于页大图、工厂照片、证书列表和微信二维码。

照片支持双语标题、说明及排序；证书包含标题和类型。图片通过媒体标识关联，服务端校验媒体存在性，引用中的图片受删除保护。

## 内容流转

1. 编辑者在后台维护文本与图片。
2. 服务端清理输入、校验引用，保存设置并记录审计。
3. 发布中心把设置差异列入待发布内容。
4. 发布导出站点数据，公开页面读取该版本的数据。

保存设置不会立即替换正式网站。正式环境实际内容以数据库和已发布快照为准，仓库 JSON 只是静态初始数据。

## 联系页现状

当前联系页提供电话、邮件、WhatsApp、微信和二维码。产品页可通过 model 查询参数传递机型提示，联系页以文本显示，供客户与厂家沟通时引用。

formEndpoint 仍存在于设置和数据结构，是兼容字段；当前页面没有在线表单，填写该字段不会自动增加提交功能。统计中保留历史 form 渠道，也不能据此判断当前页面有表单。

仓库电话、邮箱和 WhatsApp 仍包含占位值，二维码尚未配置。上线前应更新真实内容并发布，验证电话链接、邮件地址、WhatsApp 号码和二维码。

## 源码依据

- qingjin/server/src/settings/settings.service.ts：设置保存及操作审计。
- qingjin/server/src/settings/site-settings.ts：存储、媒体引用及导出。
- qingjin/admin/src/views/SettingsView.vue：维护界面。
- qingjin-site/src/data/site.json：静态配置快照。
- qingjin-site/src/pages/[lang]/contact/index.astro：实际联系页面。
