# 后台工作流、Excel 与操作审计

## 后台页面

后台路由包含仪表盘、机型列表和编辑、分类与参数模板、媒体库、站点设置、发布中心、导入导出、用户角色、操作日志及使用教程。

未登录跳转登录页；新增机型、用户管理等路由设置角色要求，详情页可用于只读查看。实际写入权限还由服务端检查。生产入口为 /admin/，history 路由需服务端回退支持。

## Excel 表结构

| 工作表 | 字段用途 |
| --- | --- |
| 机型 | slug、型号、分类、中英名称、状态、推荐及排序 |
| 参数 | slug、参数键、中英标签及值 |
| 分类 | 可选分类标识和名称 |
| 说明 | 文件填写和导入规则 |

## 导入执行顺序

1. 以 dryRun=true 检查文件，返回新增、更新、未变化项及带行号的错误。
2. 按 slug 匹配机型，不存在时新建，未出现的机型不会删除。
3. 在参数表出现的机型整体替换参数，未出现则保留。
4. 发现错误不应用，正式写入通过事务执行。
5. 图片不由 Excel 导入，新机型需单独维护图片；内容仍需发布才会上线。

预检查通过不是应用完成，也不能代替并发编辑场景验收。

## 操作审计

日志记录操作者、对象、动作、时间、差异及可用 IP 信息，覆盖产品、分类、媒体、设置、发布、用户和登录等。后台支持筛选和差异查看，删除用户后保留历史审计记录。

操作日志用于追溯，不是备份恢复文件；密码和刷新令牌原文不应作为业务差异输出。
