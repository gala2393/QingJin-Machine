# 分类、机型与媒体管理

## 分类与参数模板

分类保存唯一 slug、中英名称、图标及排序值；分类下仍有机型时拒绝删除。分类排序通过事务更新，参数模板按分类维护，重复参数键被拒绝。

模板用于统一参数键和标签，不意味着修改模板会自动改写所有已有机型的参数。

## 机型维护流程

1. 列表按关键词、分类和状态查找机型。
2. 编辑基础资料、双语参数、图片、SEO 与内部备注。
3. 服务端检查 slug 和关联数据，通过事务维护机型及子表。
4. 复制机型生成新的标识，副本设为草稿。
5. 通过批量操作调整状态、推荐或删除，分类内顺序单独维护。
6. 保存完成后进入发布流程，数据库修改不会直接替换正式站点。

型号使用规范化 modelKey，减少空格和横线等差异对检索的影响。内部备注用于维护和转录核对，不应进入公开导出。

## 图片处理链路

接收 JPG、PNG 和 WebP，解码限制为 6000 万像素；按 EXIF 旋转，校正并处理裁剪坐标，拒绝过小裁剪区。最长边不超过 1600px，不放大小图，可选白底正方形，统一输出 WebP。

媒体服务按处理后的图片摘要去重，先写临时文件再重命名。产品图片与站点图片区分用途，工厂照片和证书可不补方形。

删除媒体需检查机型及站点设置引用。当前引用保护不能替代历史发布图片依赖检查；删除只被旧版本引用的图片仍可能影响回滚。

## 源码依据

- qingjin/server/src/categories/categories.service.ts：分类、参数模板与排序。
- qingjin/server/src/machines/machines.service.ts：检索、编辑、复制、批量操作及排序。
- qingjin/server/src/media/image-processing.ts：格式、像素、裁剪和尺寸处理。
- qingjin/server/src/media/media.service.ts：上传、摘要去重及引用保护。
- qingjin/admin/src/views/MachineEditView.vue：机型编辑界面。
